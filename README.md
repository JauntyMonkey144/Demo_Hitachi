# AVEVA MES Fixbug & Support 🏭🔧

Chào mừng bạn đến với kho lưu trữ **AVEVA_MES_Fixbug**. Đây là không gian mở được tạo ra nhằm mục đích chia sẻ, thảo luận và tổng hợp các giải pháp, script, và thủ thuật xử lý lỗi (troubleshooting) thực tế cho hệ thống AVEVA MES.

## 🎯 Mục tiêu
- Cung cấp các đoạn mã (SQL Stored Procedures, VBScript, Javascript cho Dashboard) đã được tối ưu và kiểm chứng.
- Hỗ trợ xử lý các lỗi thường gặp liên quan đến theo dõi mẻ (Lot tracking), OEE, luân chuyển trạng thái thiết bị và cấu hình hệ thống.
- Xây dựng một thư viện tham khảo nhanh chóng cho các kỹ sư và lập trình viên làm việc với AVEVA MES.

## 📁 Cấu trúc thư mục (Đề xuất)
- `/SQL_Scripts`: Chứa các query và Stored Procedure (ví dụ: truy vết phả hệ Genealogy, tính toán OEE).
- `/JS_Dashboards`: Các đoạn mã Javascript can thiệp vào Highcharts hoặc giao diện Skelta BPM.
- `/VBScripts`: Script tự động hóa hoặc cấu hình trong AVEVA Edge / System Platform.
- `/Docs`: Tài liệu giải thích lỗi và cách khắc phục chi tiết.

## 🤝 Hướng dẫn đóng góp (Cách Upload file)
Rất hoan nghênh sự đóng góp từ mọi người! Để chia sẻ file hoặc giải pháp của bạn:
1. **Fork** repository này về tài khoản cá nhân của bạn.
2. Tải lên (Upload) hoặc tạo file mới trên bản Fork của bạn.
3. Tạo một **Pull Request (PR)** kèm theo mô tả ngắn gọn về lỗi và giải pháp bạn cung cấp.
4. Quản trị viên sẽ xem xét và gộp (Merge) đóng góp của bạn vào kho lưu trữ chung này.

## 📬 Liên hệ & Hỗ trợ
Nếu bạn gặp vấn đề cụ thể hoặc muốn yêu cầu một giải pháp, vui lòng mở một **Issue** mới trong tab [Issues](../../issues) và đính kèm hình ảnh/log lỗi nếu có.
